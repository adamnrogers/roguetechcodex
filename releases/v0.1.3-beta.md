# RogueTech Codex v0.1.3-beta

## Changes

**Restricted Item Handling**
- Blacklisted gear items (marked as restricted or spoiler by the developers) are now hidden from all browse and search results in the public release.
- Navigating directly to a restricted item's page shows a classified notice instead of the item detail.
- Restricted items are omitted from mech/vehicle component layout tables.

**Bug Fix**
- Fixed affinity resolution for chassis variants that use `altMaps` overrides - these now correctly take precedence over chassis-name-matched affinities.
